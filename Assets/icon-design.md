# Иконка «Голубой экран»

Встроенный imagegen; исходник: app-icon.png. Два голубых монитора с общей светящейся волной на тёмно-синей скруглённой плитке. Без текста.

Промпт (встроенный imagegen):

Use case: logo-brand. Create one polished macOS application icon for an app named Blue Screen which extends a Mac desktop wirelessly onto an Android TV. No text or letters. Square 1024x1024 composition. A premium soft three-dimensional luminous cyan monitor in the foreground and a second slightly smaller blue monitor offset behind it, communicating an extended desktop. Simple bold recognizable silhouette, front-facing almost orthographic, thick refined pale cyan glass rims, deep royal blue screen gradients with a single flowing cyan ribbon crossing both screens, small understated monitor stands. Dark midnight navy rounded-square icon tile with generous rounded corners, subtle blue halo, beautiful restrained studio lighting. Icon fills about 85 percent of canvas with generous safe padding, centered. Transparent outside the rounded square tile; absolutely no surrounding scene, no mockup, no typography, no badges, no cables, no tiny details. Must remain clear at 32 pixels.

AppIcon.icns содержит стандартные размеры macOS 16–1024 px. Android/res/drawable-nodpi/app_icon.png — вариант 192 px. build.sh и Android/build.sh включают иконки в следующие сборки.
